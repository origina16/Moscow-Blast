# Moscow Blast — платформа статистики турниров CS2

Сайт-платформа: организаторы создают турниры, добавляют игроков и загружают
демки (.dem) с Fastcup. Сайт сам разбирает демки и собирает статистику по
каждому игроку, а игроки могут смотреть турниры, матчи, карты и средние
показатели (K/D, ADR, HS%, рейтинг).

## Стек

- **Next.js 15** (App Router, TypeScript, Server Actions) + **Tailwind CSS 4**
- **Supabase** — PostgreSQL (бесплатный тариф), Auth (email/пароль), Storage (демки)
- **demofile** — парсинг демок CS2/CS:GO на Node.js

## Структура

```
supabase/schema.sql         — полная схема БД + RLS + Storage-бакет (выполнить в SQL Editor)
src/lib/supabase/           — клиенты Supabase (browser / server / admin)
src/lib/auth.ts             — текущий профиль, защита раздела организатора
src/lib/parser/demo.ts      — парсер .dem → статистика игроков
src/lib/stats.ts            — агрегация средних значений и рейтинг
src/app/actions/auth.ts     — вход / регистрация / выход
src/app/actions/organizer.ts— создание турнира, участники, загрузка демки
src/app/...                 — страницы: главная, турниры, игроки, кабинет организатора
```

## Локальный запуск

1. Установите зависимости (Node на этой машине: `F:\NodeJS`):
   ```
   $env:Path = "F:\NodeJS;$env:Path"
   npm install
   ```
2. Создайте проект на https://supabase.com (бесплатно, tier Free).
3. В Supabase → **SQL Editor** выполните целиком `supabase/schema.sql`,
   затем `supabase/migration_002_team_format.sql` (формат «6 команд × 5 игроков»).
4. В **Project Settings → API** возьмите ключи и создайте `.env.local` по образцу `.env.example`:
   - `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY` (серверный, не публиковать!)
5. Запуск:
   ```
   npm run dev
   ```
   → http://localhost:3000

Первый организатор: зарегистрируйтесь на сайте с галочкой «Я организатор турниров».
(Когда сайт станет публичным — уберите галочку из формы и выдавайте роль вручную:
`update profiles set role='organizer' where id='...'` в SQL Editor.)

## Загрузка демок

- В турнире организатора: загрузите `.dem` (GOTV-демка с Fastcup).
- Парсер извлекает: киллы, смерти, ассисты, хедшоты, урон, счёт по раундам, карту.
- Автоматически создаются игроки по никам с сервера и пишется статистика матчей.
- Средние значения считаются по всем матчам игрока автоматически.

⚠️ Парсер работает с CS:GO/CS2 GOTV-демками (поддержка demofile). Если демка с
Fastcup не поддерживается — пришлите ошибку из карточки матча, поправим парсер.

## Деплой (бесплатно)

1. Загрузите проект в GitHub-репозиторий.
2. На https://vercel.com создайте Import Project из репозитория (Free tier).
3. В настройках Vercel → Environment Variables добавьте те же 3 ключа из `.env.local`.
4. Site будет доступен на бесплатном домене вида `moscow-blast.vercel.app`
   (его можно переименовать в Settings → Domains; свой домен подключается там же).
